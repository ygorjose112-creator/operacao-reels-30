# Operação Reels 30

Plataforma editorial estática com visão geral, calendário de 30 missões, briefings completos, 150 ganchos de missão, referências e banco de 60 ganchos.

Abra `index.html` ou execute `python3 -m http.server 8000` e acesse http://localhost:8000.

Os dados estão em `data.js`. `build_data.py` importa as quatro abas editoriais da planilha de origem, adapta as menções à sequência editorial e exclui informações administrativas.
